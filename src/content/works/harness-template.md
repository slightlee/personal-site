## Background

Teams need a lightweight way to keep project planning, delivery gates, and audit evidence close to the code.

## Approach

The harness keeps lifecycle state, task modeling, validation scripts, and delivery templates in the repository so agents and humans share the same operating contract.

## Result

The workflow can move from confirmed planning to task execution with repeatable checks and traceable evidence.
