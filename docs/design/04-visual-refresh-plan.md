# 个人网站视觉精致化改版方案

## 1. 背景

当前 `personal-site` 已具备个人介绍、作品、写作、联系入口和基础响应式能力，但页面观感仍偏工程样板：首屏记忆点不足，作品与文章缺少差异化视觉承载，色彩层级偏暖米色单一。

本轮改版目标是在不改变 Astro + Markdown 内容模型的前提下，把站点提升为更成熟的个人品牌与技术博客入口。

## 2. 调研参考

参考方向：

- Framer Portfolio Templates: 作品集模板强调强首屏、作品封面和精致排版。
- Webflow Portfolio Templates: 常用清晰导航、项目预览图和强卡片节奏。
- Vercel Blog: 技术内容站点重视文章层级、留白和高可读性。
- Linear Customers: 案例页面通过克制配色、卡片层级和品牌一致性建立可信度。
- Awwwards Portfolio Inspiration: 个人作品站通常需要明确视觉记忆点，但不应牺牲内容可读性。

采纳结论：

- 个人网站不应做成 SaaS 营销首页，应保持内容优先。
- 首页需要第一屏识别度，不能只有文本和普通状态卡片。
- 作品区需要可视化承载，至少有稳定的 preview 区域。
- 写作区应采用编辑部/专栏式结构，区别于作品卡片。
- 色彩要有主色、强调色、中性色和冷色平衡，避免单一米色或大面积渐变。

## 3. 视觉定位

推荐风格：**Editorial Engineer Portfolio**。

含义：

- Editorial：像技术专栏一样可读、克制、有内容节奏。
- Engineer：体现可靠、清晰、工程可信。
- Portfolio：作品和案例有足够展示感，不停留在简历列表。

不采用：

- 大面积深色科技风。
- 大面积蓝紫渐变。
- 纯营销落地页结构。
- 重动画、3D、复杂 Canvas 背景。
- 只靠卡片堆叠的模板化布局。

## 4. 色彩方案

建议设计令牌：

```text
--color-ink: #17201f;
--color-muted: #5f6b67;
--color-paper: #f6f2ea;
--color-surface: #fffdf7;
--color-surface-cool: #e6eef0;
--color-primary: #0f766e;
--color-primary-dark: #0b4f49;
--color-accent: #d97706;
--color-border: #d8d3c7;
```

使用规则：

- `primary` 用于主按钮、关键数字、核心交互。
- `accent` 用于链接下划线、章节标记、轻量强调。
- `surface-cool` 用于作品 preview 或文章区辅助背景，平衡暖色背景。
- 背景以 `paper` 为主，卡片以 `surface` 为主。

## 5. 页面改造范围

### 5.1 Header

- 保持轻量 sticky 导航。
- 增强品牌文字和导航 hover/focus 状态。
- 移动端保持纵向或紧凑两行，避免遮挡首屏。

### 5.2 Hero

- 保留姓名、定位、简介和主要 CTA。
- 增加右侧视觉模块：个人工作台、作品截图拼贴或抽象界面预览。
- 将当前状态、可信数字和内容入口整合为更精致的信息面板。
- 首屏应露出下一段内容的开始，避免整屏封闭。

### 5.3 About / Working Principles

- 减少纯文本堆叠。
- 使用横向摘要条或分区布局呈现定位、协作方式、工程关注点。
- 仍保持真实内容，不使用功能说明式文案。

### 5.4 Works

- 每个作品卡片增加稳定 preview 区域。
- preview 可以先用 CSS 生成的抽象界面块，不强制引入真实图片。
- 卡片结构：preview、角色/年份、标题、摘要、标签。
- 桌面端保留 3 列，移动端单列。

### 5.5 Writing

- 改为编辑部风格列表。
- 文章条目突出标题、日期、标签和摘要。
- 与作品卡片形成视觉区分，避免所有内容都是同一种卡片。

### 5.6 Detail Pages

- 作品详情和文章详情保持阅读优先。
- 优化正文段落宽度、标题间距、元信息卡片。
- 不引入复杂交互。

## 6. 实施约束

- 不引入设计系统库。
- 不引入运行时 JS 交互，除非后续有明确需求。
- 优先通过 `global.css` 设计令牌和已有 Astro 模板完成。
- 不改变 Markdown 内容模型，除非后续需要真实封面图字段。
- 不做 CMS、登录、评论、主题切换。

## 7. 验收标准

- 首屏具备明确视觉记忆点和个人品牌感。
- 主色、强调色、背景、卡片和链接状态统一。
- 作品区具备 preview 视觉载体，文章区具备专栏式阅读节奏。
- 桌面端和移动端文字不重叠、不溢出。
- 卡片圆角不超过 8px。
- Focus 状态清晰可见。
- `pnpm run lint`、`pnpm run typecheck`、`pnpm run test`、`pnpm run build` 通过。
