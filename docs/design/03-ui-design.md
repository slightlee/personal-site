## 2. UI 设计目标

`personal-site` 的界面目标是建立一个简洁、可信、现代的个人品牌网站。它应该像成熟互联网产品一样清晰、克制、可扫描，而不是像临时简历页或过度装饰的展示页。

核心体验目标：

- 首屏快速传达“我是谁、擅长什么、如何联系”。
- 首屏不仅展示身份，还要展示明确价值主张、可信信号和主要内容入口。
- 作品集有清晰的信息层级，方便快速判断质量和相关性。
- Markdown 作品详情具有良好的阅读体验。
- 移动端和桌面端都保持专业、稳定、不拥挤。
- 站点可见文案以中文为主，英文仅用于技术词、项目名和外部链接名称。

## 3. 目标用户与使用场景

- 招聘方：快速了解能力、项目经验和联系方式。
- 合作方或客户：判断专业方向、审美和交付可信度。
- 同行开发者：查看作品、技术栈和项目案例。
- 作者本人：长期维护内容，并把网站作为公开名片。

设备优先级：

- 桌面端：作品浏览和详情阅读体验优先。
- 移动端：首屏介绍、联系方式和作品扫描必须顺畅。

## 5. 页面设计

### 5.1 首页

首页采用纵向内容流，不做复杂多层导航。首屏必须包含：

- 姓名或展示名。
- 一句话职业定位。
- 2 到 3 行个人简介。
- 联系入口。
- GitHub 或其他社交链接。
- 2 到 3 个可信信号，例如交付流程、测试覆盖、内容维护方式或代表方向。

首页下方依次展示：

- About：更完整的个人介绍。
- Working Principles：工作方式、工程原则或协作偏好。
- Skills：核心能力，使用短标签。
- Featured Works：精选作品卡片。
- Writing / Notes：文章、观点或后续写作入口，首版可放精选占位内容。
- Contact：邮箱、社交链接和合作说明。

### 5.2 作品列表

作品卡片应包含：

- 标题。
- 简短摘要。
- 角色或项目类型。
- 标签。
- 日期或年份。
- 详情入口。

卡片不应过度装饰，重点是信息清晰和阅读节奏。

### 5.3 作品详情

作品详情页以阅读体验为核心：

- 顶部展示标题、摘要、角色、标签和日期。
- 正文使用 Markdown 渲染，保持良好的段落宽度。
- 图片或截图可选，必须有稳定尺寸，避免布局跳动。
- 末尾提供返回作品列表和外部链接。

## 6. 视觉规范

### 6.1 风格关键词

- 简洁。
- 现代。
- 内容优先。
- 专业可信。
- 轻量高级感。

### 6.2 色彩

建议使用中性色为主，搭配两个低饱和强调色，避免一眼看成单一色系：

- 背景：接近白色或轻微冷灰，可使用极轻纸张感层次。
- 正文：高对比深色。
- 次级文本：中性灰。
- 主强调色：用于按钮、链接和焦点态。
- 辅助强调色：用于数据、章节标记和轻量信息块。

避免：

- 大面积渐变。
- 过强的单一色系。
- 低对比文本。

### 6.3 字体

首版使用系统字体栈，避免引入额外字体文件：

```css
font-family: Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;
```

标题使用明确层级，但不使用负字距，不使用随 viewport 连续缩放的字体策略。

### 6.4 间距与布局

- 页面最大宽度控制在舒适阅读范围。
- 桌面端使用 2 到 3 列作品卡片。
- 移动端使用单列。
- 卡片圆角不超过 8px。
- 不使用卡片套卡片。

### 6.5 图像与媒体

首版可以不强制使用作品封面。如果使用图片：

- 需要明确展示作品真实内容。
- 需要固定宽高比或稳定尺寸。
- 避免纯氛围图、模糊图和无意义装饰图。

## 7. 交互规范

- 导航：首版可使用简洁顶部导航或页内锚点。
- 联系入口：主按钮使用 `mailto:`。
- 作品入口：卡片整体或明确链接进入详情。
- Hover：只使用轻微颜色、边框或位移变化。
- Focus：键盘焦点必须可见。
- 空状态：作品为空时展示简短说明，不使用营销式长文案。

首版不做：

- 复杂滚动动画。
- 页面加载动效。
- 鼠标跟随特效。
- 3D 或 Canvas 背景。

## 8. 响应式规则

### 8.1 移动端

- 单列布局。
- 首屏内容紧凑但不拥挤。
- 联系按钮和链接容易点击。
- 作品卡片完整展示，不横向滚动。

### 8.2 桌面端

- 首屏可以使用左右布局或强排版布局。
- 作品区使用 2 到 3 列。
- 正文阅读宽度不超过约 760px。

### 8.3 宽屏

- 内容不无限拉伸。
- 保持居中容器和稳定最大宽度。

## 9. 可访问性要求

- 每页只有一个清晰的 H1。
- 标题层级按顺序组织。
- 链接和按钮有明确可见文本。
- 键盘 Tab 顺序自然。
- Focus 状态清晰。
- 文本与背景对比度合理。
- 图片提供 alt，装饰图应明确为空 alt。

## 10. 验收标准

- 首页首屏能清晰展示姓名、定位、简介和联系入口。
- 作品卡片信息完整，移动端不溢出、不重叠。
- 作品详情正文可读，段落宽度舒适。
- Hover 和 Focus 状态可辨识。
- 颜色对比满足基本可读性。
- 无大面积装饰性渐变、无无意义背景图、无复杂炫技动效。

- 首页必须是个人品牌入口，而不是只有作品卡片的目录页。
- 内容结构要覆盖定位、工作方式、代表成果、精选作品、写作入口和联系入口。
- 视觉系统要统一，形成稳定的颜色、间距、卡片和标签规则。
- 面向国内使用场景，可见文案以中文为主，英文只保留技术名词、项目名和外部品牌。
